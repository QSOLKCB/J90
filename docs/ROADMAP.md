# J90 roadmap

## v0.1.0 — foundations (this PR)

- Exact quarter-turn and floating-point arbitrary-angle rotations.
- Closed-form, optionally damped quadrature oscillator.
- Deterministic no-clock pause/restore versus continued-evolution protocol.
- Strict canonical JSON checkpoint with SHA-256 integrity.
- CLI reports, standard-library tests, interactive dependency-free browser demo.
- Attribution and scientific claim boundaries.

## v0.2.x — adversarial controls

### v0.2.0 — implemented in this PR

- Executable seven-case null registry, independent scalar analytical oracle and fixed 24-case boundary sweep.
- Explicit clock, sensor and recorded-memory inputs, with per-channel evidence and strict validation.
- Declared absolute/relative numeric comparison budgets and fail-closed control report CLI.
- Interactive browser challenge panel, and test-gated Pages deployment.

### v0.2.1 — independent cross-runtime replay (this PR)

- 8 fixed Node.js ↔ Python stdlib scenarios with 40 integrity-checked checkpoints, 32 repeated replay segments and 112 comparisons.
- Independent Python math integration, restored-state and resumed-state comparisons, error-budget sensitivity and JSON integrity/tampering tests.
- Deterministic JSON report with SHA-256 manifest/report receipts. Node's JavaScript-specific JSON canonicalization remains authoritative for emitted checkpoints.
- One test-gated existing GitHub Pages workflow configures Python 3.12 and runs cross-runtime parity; public site remains unchanged.

### v0.2.2 — observer access, provenance limits and float64 boundaries (this PR)

- Seven existing null scenarios evaluated under five explicit channel-access profiles (35 projections). No hidden sensor or elapsed-time access.
- Source-labelled synthetic clock/sensor/record events with strict sequential SHA-256 integrity chain, rejection of tampering/reordering/malformed inputs, and a test proving that recomputed hashes do **not** authenticate forged assertions.
- Deterministic 450-case float64 sweep crossing three amplitude regimes, six frequencies, five dampings and five gap durations; conventional and exact-zero tolerance comparisons, underflow classification and report checksums.
- Six additional independent Node/Python replay stress scenarios (24 segments, 30 checkpoints, 84 comparisons), deliberately separate from the original v0.2.1 corpus.
- CLI `npm run evidence`, documentation and test-gated CI; browser site unchanged.

### v0.2.3+ — deferred research

- Real multi-platform/OS differential benchmarks with published environment provenance; do not infer global portability from Ubuntu CI.
- Explicit external measurement ingestion with authenticated source identity if a trust system is ever needed. SHA-256 chains alone cannot establish authenticity.
- Broader error-budget sensitivity and versioned reproducibility archives; first specify cross-language canonical JSON before supporting Python-issued checkpoints.

## v0.3.x — nonlinear comparison

- Mandelbrot/Julia iteration as a **separate nonlinear model class**.
- Explicitly state why complex multiplication by i is not the same as the nonlinear map z -> z^2+c.
- Compare invariants, bifurcations and sensitivity with linear quadrature; no automatic "emergence" inference.

## v0.4.x — dimensional-transposition claims

- Obtain and pin stable versioned primary source(s); extract each proposed operator and its domain/codomain.
- Check exact mathematical preservation, invertibility, composition and counterexamples.
- Keep the conjecture distinct from existing transform theory and physical empirical claims.

## Long-term

- Evidence ledger, reproducible figures, versioned experiment receipts and public demonstration video.
- No feature expansion or claims without tests, scoped PRs and clear attribution.
