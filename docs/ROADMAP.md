# J90 roadmap

## v0.1.0 — foundations (this PR)

- Exact quarter-turn and floating-point arbitrary-angle rotations.
- Closed-form, optionally damped quadrature oscillator.
- Deterministic no-clock pause/restore versus continued-evolution protocol.
- Strict canonical JSON checkpoint with SHA-256 integrity.
- CLI reports, standard-library tests, interactive dependency-free browser demo.
- Attribution and scientific claim boundaries.

## v0.2.x — adversarial controls

- Formal null-model registry, analytical oracle and boundary sweeps.
- Repeated checkpoint/resume across different runtimes, rounding/error budgets.
- Paired experiments with an external timestamp, sensor input and observable memory; specify who has access to which data.

## v0.3.x — nonlinear comparison

- Mandelbrot/Julia iteration as a **separate nonlinear model class**.
- Explicitly state why complex multiplication by i is not the same as the nonlinear map z -> z^2+c.
- Compare invariants, bifurcations and sensitivity with linear quadrature; no automatic "emergence" inference.

## v0.4.x — dimensional-transposition claims

- Obtain and pin stable versioned primary source(s); extract each proposed operator and its domain/codomain.
- Check exact mathematical preservation, invertibility, composition and counterexamples.
- Keep the conjecture distinct from existing transform theory and physical empirical claims.

## Long-term

- Evidence ledger, reproducible figures, versioned experiment receipts and public demonstration video.
- No feature expansion or claims without tests, scoped PRs and clear attribution.
